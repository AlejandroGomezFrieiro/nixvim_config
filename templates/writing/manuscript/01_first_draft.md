# Untitled

Put the opening words here. Later chapters are sibling files in `manuscript/`
(`02_second_act.md`, `03_turning_point.md`, ...); `just words` and `just export`
pick them all up.

Start writing in plain markdown. Opening a `.md` file enters writing mode:
word wrap, spell check, and (with focus on) Twilight + Goyo so the page is all
you see. Grammar (LTeX) and style (Vale) checks run as you type.
